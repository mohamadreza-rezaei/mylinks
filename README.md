# mylinks

Cloudflare Worker that redirects personal and social profile links from a single config.

**Live:** https://mylinks.mohamadreza-rezaei.workers.dev/

## Stack

- Cloudflare Workers
- Wrangler

## Setup

```bash
npm install
```

## Develop

```bash
npm run dev
```

## Deploy

```bash
npm run deploy
```

Configure routes and link targets under `src/` and `wrangler.toml`.
